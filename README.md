# 🛒 Clothes E-Commerce Website — Dockerized Application

## 📌 Project Overview

This project demonstrates the containerization of a PHP-based
E-Commerce web application using Docker.

I took an existing PHP E-Commerce application and built a
Docker-based development environment with PHP, Apache and MySQL.

## 🐳 Docker Implementation

- Created a custom Dockerfile
- Built a Docker image for the PHP application
- Created and managed Docker containers
- Configured Apache and port mapping
- Created a custom Docker network
- Configured a separate MySQL container
- Connected the PHP application with MySQL
- Implemented Docker Compose for multi-container setup
- Used environment variables with `.env`
- Added `.dockerignore`
- Tagged the image for Docker Hub
- Practiced Docker troubleshooting and container management
